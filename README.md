# GitHub Profile Finder (React)

A React app that searches any GitHub username and shows their profile and latest repositories.

## Live Demo
https://syedhummadhyaseen.github.io/github-finder-react/

## Features
- Search by username with the Search button or the Enter key
- Shows avatar, name, bio, public repos, followers and following
- Lists the 5 most recently updated repositories
- Loading, empty input and user not found states

## Technologies
- React
- Vite
- JavaScript
- GitHub REST API

## What I learned
- Building components with JSX
- Managing data with the useState hook
- Fetching data from an API with async/await
- Conditional rendering and rendering lists with map
